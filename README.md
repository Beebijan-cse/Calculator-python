# Calculator-python

A simple calculator program written in Python. It takes two numbers and shows the results of basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Floor division
- Modulus
- Exponentiation

## How to run

Make sure Python 3 is installed, then run `python calculator.py`.

Enter two numbers when prompted. For division, floor division, and modulus, the second number must not be zero.
