# Python Calculator

A beginner-friendly command-line calculator written in Python. Enter two numbers to see the results of basic arithmetic operations.

## Features

- Addition, subtraction, and multiplication
- Division, floor division, and modulus
- Exponentiation
- Checks that inputs are valid finite numbers
- Handles division by zero
- Handles exponent results that are too large

## Requirements

- Python 3
- No external packages

## How to Run

Open a terminal in the project folder and run:

```bash
python calculator.py
```

Enter the first and second numbers when prompted. The calculator will display the results.
